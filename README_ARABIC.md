## خطوات التشغيل (مرة واحدة بس - 5 دقايق)

### 1️⃣ اعمل بوت تليجرام
1. افتح تليجرام ودور على: **@BotFather**
2. ابعتله: `/newbot`
3. اختار اسم ثم username بينتهي بـ `bot`
4. انسخ **التوكن** وحطه في `config.json` مكان `ضع_توكن_البوت_هنا`

### 2️⃣ هات الشات ايدي بتاعك
1. دور على **@userinfobot** في تليجرام
2. ابعتله أي رسالة → هيديك رقم **Id**
3. حطه في `config.json` مكان `ضع_الشات_ايدي_هنا`

### 3️⃣ جرب الاتصال
```
python run_bot.py --test
```
لو وصلتك رسالة ✅ تمام

### 4️⃣ شغّل البوت خلاص
```
python run_bot.py
```
سيب اللاب توب شغال — أول ما تنضبط صفقة في أي سوق هتوصلك رسالة فيها:
- 🟢 شراء / 🔴 بيع
- 🎯 سعر الدخول | 🛡️ وقف الخسارة | 💰 الهدف

## أوامر مهمة

| الأمر | بيعمل إيه |
|-------|-----------|
| `python run_bot.py` | تشغيل المراقبة المباشرة |
| `python run_backtest_main.py` | اختبار الأداء على السوق الحقيقي |
| `python sweep.py` | تجربة إعدادات وقف/هدف مختلفة |

## تعديل الإعدادات (config.json)
- `crypto_symbols`: العملات الرقمية المراقبة
- `market_symbols`: فوركس + ذهب + مؤشرات + نفط
- `timeframe`: `15m` أو `1h`
- `cooldown_hours`: مهلة بين كل إشارة لنفس العملة

## ⚠️ بصراحة
- النسب دي محسوبة على بيانات تاريخية — السوق بيتغير ومفيش ضمان
- البوت أداة انضباط وتوفير وقت، القرار والأفلوس مسؤوليتك
- متتاجر بفلوس مش قادم عليها
